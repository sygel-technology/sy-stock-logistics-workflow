Usage
=====

To use this module, you need to:

1. Choose any inventory transfer.
2. Once in the transfer form view, go to the "Additional Info" tab
3. In this tab, locate the Weight for shipping field.
4. This field will now have a button that enables us to make manual
   weight changes to the shipment.
5. If we click on the button, a wizard will open that allows us to
   specify the new value for shipping weight
