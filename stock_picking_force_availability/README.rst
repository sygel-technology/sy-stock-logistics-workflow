This module allows you to force the availability of unavailable products
from a delivery order.

To be able to force availability, two conditions must be met:

1. The status of the operation is 'Waitting'.
2. The 'Operation Type' allows to force the availability.

Configuration
=============

To configure this module, you need to:

1. Go to module 'Inventory' -> 'Configuration' -> 'Operations Types'.
2. Edit or Create a new Operation Type.
3. Check the box 'Allow to Force Availability'.

Usage
=====

To use this module, you need to:

1. Create a quotation with unavailable products
2. Confirm the quotation
3. Go to the generated delivery order
4. Click on 'Force Availability' to force the availability of the
   products.

Known issues / Roadmap
======================

Currently, this module only allows you to force the availability of
products without traceability. This means that it does not allow to
force the availability of products with serial or lot number.

We will consider adding them in future updates.
